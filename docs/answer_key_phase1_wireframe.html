Answer Key — Phase 1 Wireframe (Actual Implemented Behavior)

These phone states reflect the shipped Phase 1 flow: a 3-stage Structure → Enter → Review model with a canonical AnswerKeySection persisted per assessment. Uniform exams get a fast path; mixed exams are edited as typed sections. Section-aware bulk input and global Paste-All both show a typed preview before applying. Legacy assessments (no stored sections) derive their structure from existing question types.
